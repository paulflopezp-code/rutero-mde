📥 Importar Rutas

Carga rutas masivamente desde CSV o descríbelas en texto y la IA genera el formato automáticamente.

📊 Método A — Importar desde CSV

⬇️ Descargar plantilla

Descarga la plantilla Excel/CSV, llena los datos de tus rutas (una por fila) y súbela aquí. Los campos separados por | permiten múltiples valores (sitios, consejos, GPS).

📂
Arrastra el CSV aquí
o haz clic para seleccionar

📋 Método B — Pegar JSON directo

COPIA → PEGA → SUBE

Pegá el JSON completo de una ruta (generado por Claude u otra fuente). Soporta sitiosDetalle con tips, curiosidades, retos y horarios.

🤖 Método C — Generar ruta completa con IA

POWERED BY CLAUDE · v2 SITIOS DETALLE

Describe la ruta en lenguaje natural — la IA genera ruta + sitios con horarios, tips, curiosidades y retos en ES/EN, listos para Firestore.

📍 Sitios detallados 🕐 Horarios 💡 Tips locales 🧠 Curiosidades 🎯 Retos gamificados 🇬🇧 ES + EN
✅ Ruta generada con sitios detallados

🗺️ Método D — Importar Capa del Mapa

capas_mapa → Firestore

Importa capas de movilidad u otros puntos de interés (EnCicla, Whoosh, etc.) a la colección capas_mapa en Firestore. El JSON debe tener un campo capaId que será el ID del documento.

📚 Método E — Importar Colección Genérica

cualquier colección → Firestore

Importa documentos a cualquier colección de Firestore (tips, traducciones, etc.).
Formato esperado: { "coleccion": "nombre_coleccion", "documentos": [ { "nombre": "...", ... } ] }
El campo nombre de cada documento se usa como ID en Firestore.
